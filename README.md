# 📊 Amazon Revenue Growth Analysis Dashboard | Excel & Power Query

## 📌 Project Overview

This project analyzes Amazon sales and revenue data using Microsoft Excel and Power Query. The objective is to understand revenue trends, evaluate pricing patterns, and explore performance across departments, buyer segments, and merchant categories.

An interactive Excel dashboard was developed to summarize key performance indicators and support data-driven business analysis.

## 🎯 Business Objectives

- Analyze yearly revenue and sales performance.
- Evaluate Average Selling Price (ASP) patterns.
- Compare performance across product departments.
- Analyze buyer and merchant category trends.
- Identify potential pricing and business improvement opportunities.
- Present insights through an interactive dashboard.

## 🛠️ Tools & Techniques

- **Microsoft Excel:** Data analysis and reporting
- **Power Query:** Data cleaning and transformation
- **Pivot Tables:** Data aggregation and segmentation
- **Pivot Charts:** Performance visualization
- **Excel Formulas:** KPI calculations
- **Dashboard Design:** Interactive reporting and business insights

## 📈 Analysis Performed

- Year-over-year revenue analysis
- Department-level performance analysis
- Buyer category analysis
- Merchant category analysis
- Transaction count analysis
- Average Selling Price (ASP) evaluation
- KPI reporting and dashboard visualization

## 📊 Key Findings

- Revenue increased by approximately **54.5% between 2014 and 2017**, based on the revenue values in the dataset.
- The weighted ASP proxy fluctuated across the analyzed years rather than showing a consistent overall decline.
- Department-level and customer-segment analysis can help identify areas for further pricing and performance investigation.

*Note: Findings should be interpreted using the dataset's field definitions and validated calculations. Segment-level ASP conclusions should be added after the detailed analysis is verified.*
